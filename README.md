# SOPA! Cedar Crest

One-page static site for SOPA!. A single self-contained `index.html` (logo embedded, fonts from Google Fonts). No build step.

## Deploy on Cloudflare Pages
- Framework preset: None
- Build command: leave blank
- Build output directory: `/`

## Edit
- Hours: the table in `index.html`, and the `HOURS` array in the script at the bottom (used for the "today" highlight)
- Colors: the variables at the top of the `<style>` block
- Order link: `https://www.primeraagua.com` (three places)
